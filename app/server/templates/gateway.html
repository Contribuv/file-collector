先说清楚这是个啥

说白了，它就是一个帮你“收文件”的小工具。你建一个链接，把链接发到微信群里，大家点开链接就能把文件传给你。收上来的文件，你还能自动按“谁传的”分好类，再开一个分享页让大家一起看、一起下载。

常见用法比如：老师收学生作业、部门收大家的工作资料、组织活动收集照片视频。你不用建一堆微信群，也不用一个个催人家私聊发你。

一、先把应用装上

这是飞牛 fnOS 的专属应用，装起来和装别的应用差不多。

  1. 先把安装包（.fpk 结尾的文件）下载到电脑或 NAS 上。
  2. 打开飞牛的桌面，进到应用管理里，找“手动安装”，选这个文件。
  3. 安装过程中会让你设置两样东西：管理员账号密码、监听端口。端口默认 5557，没有特殊需要就别动它。
  4. 等几秒钟，装完。桌面上会出现它的图标。

装完之后，在浏览器地址栏输入下面的地址就能打开：

http://你NAS的IP:5557/admin

以后要升级，直接在应用商店点升级就行，数据都会保留，不会丢。

二、第一次登录，记得把密码改了

刚装好的应用有一个默认账号，登录的时候直接填这个：

用户名admin
密码admin123
第一次登录后，它会强制让你改一个新密码。这个新密码要记好，别再留着默认的 admin123，不然别人随便就登进来了。

三、建一个收集链接

想开始收东西，就建一个收集链接。登录后台，点左边菜单的「收集链接」，再点「创建收集链接」。

表单里几个关键的地方说一下：

  • 收集名称：给这次收集起个名，比如“语文作业收集”。
  • 收集描述：告诉别人要传些什么，比如“请上传本周语文作业的照片，周末前交”。
  • 空通行证：勾上了，链接就完全公开，别人点开不用输密码；不勾，就得设一个密码，把密码一起发给对方。
  • 开启分享页：勾上，除了收文件还会多生成一个“分享页”，别人能在上面看和下载已经收上来的文件。一般建议勾上。
  • 上传者登记：勾上，对方传之前得先填自己的名字，文件会按名字自动分文件夹存，谁传的一目了然。收作业这种场景强烈建议勾。
  • 单文件上限 / 上传数量上限：限制单个文件多大、每人最多传几个。默认值一般够用。

填完点保存，这个链接就算建好了。

四、链接建好了，怎么发给别人

回到「收集链接」列表，能看到所有建好的链接。每个链接下面都有“复制”按钮，会复制两个地址，分别对应两种页面：

  • 收集页链接：给别人传文件用的，发群里。
  • 分享页链接：给别人看/下载文件用的，需要的时候发。

列表里每个链接都能单独编辑（改密码、改限额）、禁用（禁了链接就失效，别人打不开）、删除。放心删，已经上传的文件还留在硬盘上，不会没。

五、对方怎么传文件给你

下面站在“上传的人”的角度看一遍，老师你直接把这部分截图发群里都行，省得解释。

第 1 步：打开链接，先填自己的名字

开了“上传者登记”的话，打开页面会先弹个小窗让你填昵称，填完点确认。

第 2 步：把文件拖进来，或者点选

有两种方式：直接把文件拖到中间那块上传区；或者点上传区的按钮自己选文件，一次能选多个。选完点“开始上传”，盯着进度条就行。

文件比较大也无所谓，它支持断点续传，传一半断网了，重新连上会自动接着传，不用从头再来。

第 3 步：看到文件出现在“已上传”里，就成了

手机也能传。用手机浏览器打开链接，操作和电脑上一样。

六、收来的文件，大家怎么查看和下载

因为建链接的时候勾了“开启分享页”，所以你在「收集链接」列表里还能复制到一个分享页链接。把它发给想看文件的人，对方打开就是这个样子：

分享页上每个文件后面有两个按钮：

  • 预览：不用下载，直接在网页里看。图片、PDF、Word/Excel、视频、声音、TXT 文本都支持。
  • 下载：存到自己设备上。

文件多的话，可以勾选好几个一起打包下载（一个 ZIP），或者直接点“下载全部”一把梭。

七、后台还能干点什么

后台就是 /admin 那个地址，左侧一排菜单，常用的就三个：

信息面板

一登录先看到的就是它。上面是几个数：建了多少链接、有几个是活跃的、一共收了多少文件、今天收了多少。下面“最近上传”列的是最新传上来的文件。

文件记录

所有收上来的文件都在这里，像一个总仓库。可以按链接筛选，也能分页翻。每个文件都能预览、下载、删除，勾选好几个还能批量下载、批量删。

其他两个

  • 用户管理：管理能登录后台的账号，加人、停用、重置密码都在这里。
  • 设置：所有系统配置都在这，下一节逐项讲。
记住：/admin 这个后台地址和密码，自己留着就行，别发给别人。发出去的应该是收集页和分享页的链接。

八、后台「设置」页，逐项说清楚

后台左侧点「设置」进来，所有的系统配置都在这张页面上，一屏装不下。下面按从上到下的顺序，把每一块讲明白。

1. 账号设置

改你自己的后台账号信息：

  • 管理员用户名：登录后台用的账号名。
  • 昵称：批注为必填。这个昵称会显示在收集页和分享页上，别人看到的"xx邀请您上传文件"用的就是它。不填的话，页面会显示用户名。
  • 邮箱：填了才能用登录页的"忘记密码"功能找回密码；配好 SMTP 后，会直接发验证码到这个邮箱。
  • 当前密码 / 新密码 / 确认新密码：改任何信息都要验一次当前密码；想换密码就填后面两个，不换留空。

2. 邮箱设置 (SMTP)

这一块是给"忘记密码"用的。想要系统能从你的邮箱发验证码，就得配这里：

  • SMTP 服务器地址：邮箱服务商给的，QQ 邮箱填 smtp.qq.com。
  • 加密方式：STARTTLS（端口 587）或 SSL（端口 465），跟着邮箱服务商的要求选。
  • 邮箱账号、密码/授权码：QQ 邮箱这类一般要用"授权码"，不是登录密码。
  • 发件人名称、发件人邮箱：别人收到邮件时看到的名字和地址。
  • 配完可以点「发送测试邮件」，系统会往发件人邮箱发一封，收到就说明配通了。

3. 页面与品牌

各个页面上显示的字，都在这改。不想折腾可以全不填：

  • 站点标题：显示在浏览器标签和页面顶部。
  • 分享页标题：不填就沿用站点标题。
  • 公网网址：在统一网关配好反向代理后这里自动带上公网地址；也可手动填第三方反代域名。
  • 收集页页尾、分享页页尾：页面底部的说明文字，比如"有问题请联系李老师"。
  • 登录页提示：后台登录页底部的提示信息。

4. 默认设置

新建收集链接时的默认值。创建链接时不单独设，就用这里的默认：

  • 默认最大文件数 / 单文件上限：每个链接默认能收几个文件、单个文件多大。
  • 单次最多上传个数：上传的人一次最多选几个文件，默认 30。填 0 表示不限制，想传多少传多少；最大 500。
  • 通行证缓存有效期：输一次密码（通行证）管多久，默认 120 分钟，到期重新输。
  • 链接最大有效期：新建链接能设的最长有效期（天）。
  • 禁止上传文件类型：黑名单，默认禁 .exe .php .sh .bat 这类危险文件。想再加就空格分隔写上，如 .exe .php .sh .bat .html。
  • 收集附件上限：创建链接时上传附件图的最大限制，默认 1000 MB。
  • 每页数量：链接列表、文件记录列表每页显示几条。

5. 上传路径

文件默认存在系统盘，想存到别的硬盘就填自定义目录（如 /vol2/1000/文件收集）。改完需要在飞牛应用中心给这个目录加权限，再重启应用才会生效。

6. 功能开关

  • 开放用户注册：开启后别人能用邀请码注册你的后台账号。
  • 启用首页介绍页：开启后访问首页看到的是介绍页。
  • 根目录创建文件夹：开启后，收上来的文件直接按"收集名称"建文件夹放在上传根目录，不再按用户名分层；即使开了上传者登记，也不建上传者子文件夹。

7. 数据库管理

  • 路径自动同步：改了上传路径，系统会自动同步数据库里的记录，不用手动处理。
  • 备份数据库：把整个数据库下载成 .db 文件存本地，搬家或存档用。
  • 恢复数据库：上传 .db 备份恢复；恢复前系统会自动再备份一份当前的，不怕误操作。

8. 系统信息

只读区域：开发者、数据库类型、版本号、监听端口、数据目录和上传目录的位置，出问题报错时把这里告诉开发者。

九、批量功能：一次建一堆链接

如果你要同时建很多个收集链接（比如给 30 个班每个班建一个作业收集），一个个点太累，用批量创建。后台「收集链接」列表右上角有「＋ 批量创建」按钮：

操作步骤

  1. 点「下载模板文件」，拿到一个 Excel 表格（表里前两行是演示数据，不会真的建出来，放心）。
  2. 按列填：收集名称是必填的；其他列（描述、通行证、最大文件数量、单文件上限、有效期、是否允许删除、显示预览按钮、上传者登记、自定义链接、分享页开关等）空着就用系统默认值。通行证列空着 = 这个链接不需要密码。
  3. 保存成 CSV（Excel 里"另存为 CSV"，建议 UTF-8 编码），拖到上传区或点选文件。
  4. 等几秒出结果：成功建了哪几个、哪几行哪列填错，会一条条列出来。

列表里的批量操作

除了批量创建，链接列表和文件记录列表都有「批量操作」按钮，点开变成勾选模式：

  • 收集链接列表：勾选多个链接，可以一次批量删除。
  • 文件记录列表：勾选多个文件，能批量打包下载（合成一个 ZIP）或批量删除。收上来几百个文件想一起拷走，用这个最省事。

十、补充：想让外面的人也能访问

文件收集器默认只监听内网端口，家里/公司的局域网能访问，外面网络访问不了。想让外面的朋友也能用，需要配反向代理，把端口暴露到公网。飞牛自带的统一网关就是干这个的。

  • 通过反向代理，把服务暴露到公网，走 HTTPS 加密
  • 证书自动从飞牛系统读取，不用自己申请
  • 支持多台设备同时在线

先做两件准备工作

  1. 开 DDNS，拿到域名：在飞牛系统里打开「DDNS」，添加一条解析，绑上你家宽带的动态公网 IP。成功后你会得到一个域名，比如 xxx.fnos.net。这一步的作用，是把外面访问的网址和你家公网 IP 绑定起来。
  2. 确认域名有证书：飞牛系统会自动给 DDNS 域名申请证书。证书是 HTTPS 加密用的，没有它，HTTPS 访问会报"不安全"。证书的事一般在飞牛系统里勾选"自动申请"就行，不用手动操作。

操作步骤（都在「公网访问」这个 tab 里完成）

进入应用后，点左侧栏的「公网访问」，页面长这样：

第 1 步：选域名

「域名」下拉框里，会自动列出飞牛系统里能用的证书域名，挑之前 DDNS 绑定的那个域名。列表是空的？点下方「刷新证书」按钮再试试；还是没有，说明飞牛系统里 DDNS 和证书没弄好，回到前面准备工作检查。

第 2 步：填 HTTPS 端口

默认填好 7786。一般不用改。如果提示"端口被占用"，页面会给出备用端口建议（7787、7788），点一下换掉就行。记下这个端口号，后面路由器要用。

第 3 步：点「启动」

点蓝色「启动」按钮，状态变成运行中，反代就起来了。以后想关掉就点它旁边的「停止」。

别忘了路由器：请在路由器管理页做「端口转发」（有的路由器叫"端口映射/虚拟服务器"），把第 2 步那个 HTTPS 端口转发到 NAS 的内网 IP。不做这一步，外面还是连不进来。

第 4 步：浏览器验证

在外面（手机流量、公司网络）打开 https://你的域名:端口号，能打开就成功了。比如域名是 xxx.fnos.net、端口 7786，地址就是 https://xxx.fnos.net:7786。注意前面带 https://，别漏了。

家里宽带如果没有公网 IP（运营商不给你，或你在路由器的"大内网"里），DDNS 拿到域名也连不进来。这种情况可以在路由器上开 UPnP、去运营商要公网 IP，或者用别的穿透方案，那是另一套玩法了。
