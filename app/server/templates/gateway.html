先说清楚这是个啥

说白了，它就是一个帮你“收文件”的小工具。你建一个链接，把链接发到微信群里，大家点开链接就能把文件传给你。收上来的文件，你还能自动按“谁传的”分好类，再开一个分享页让大家一起看、一起下载。

常见用法比如：老师收学生作业、部门收大家的工作资料、组织活动收集照片视频。你不用建一堆微信群，也不用一个个催人家私聊发你。

一、把应用装上，从哪进

这是飞牛 fnOS 的专属应用，装起来和装别的应用差不多。

  1. 先把安装包（.fpk 结尾的文件）下载到电脑或 NAS 上。
  2. 打开飞牛的桌面，进到应用管理里，找“手动安装”，选这个文件。
  3. 安装过程中会让你设置两样东西：管理员账号密码、监听端口。端口默认 5557，没有特殊需要就别动它。
  4. 等几秒钟，装完。桌面上会出现它的图标。

两种进入方式

  • 推荐：从飞牛桌面点图标直接进。应用会以“独立小窗”的方式嵌在飞牛桌面里打开，用你的飞牛账号自动登录，不用再单独记一套账号密码。整套管理面板、收集链接、文件记录都在这个窗口里。
  • 备用：浏览器直连独立后台。在地址栏输入 http://你NAS的IP:5557/admin，用下面的默认账号登录。这个入口只建议在本机/内网排障时使用。
以后要升级，直接在应用商店点升级就行，数据都会保留，不会丢。日常使用建议只从飞牛桌面进入。

二、第一次进来，先把密码设好

从飞牛桌面打开应用时，系统已经用你的飞牛账号登录好了，默认就能用，不需要额外注册。

第一次进入时，如果右上角或「收集设置 → 账号设置」提示“尚未设置登录密码”，建议顺手设一个：填好新密码（至少 8 位，需同时包含字母和数字）点保存即可。这样即使换了浏览器或设备，也能用账号密码登回来。

如果你走的是独立后台（/admin）

刚装好的应用有一个默认账号，登录时直接填：

用户名admin
密码admin123
第一次登录独立后台后，它会强制让你改一个新密码。这个新密码要记好，别再留着默认的 admin123，不然别人随便就登进来了。

三、建一个收集链接

想开始收东西，就建一个收集链接。在左侧点「收集链接」，再点右上角的「＋ 创建收集」，会弹出一个创建窗口。

窗口里几个关键的地方说一下：

  • 收集名称：给这次收集起个名，比如“语文作业收集”。
  • 收集描述：告诉别人要传些什么，比如“请上传本周语文作业的照片，周末前交”。
  • 空通行证：勾上了，链接就完全公开，别人点开不用输密码；不勾，就得设一个密码，把密码一起发给对方。
  • 开启分享页：勾上，除了收文件还会多生成一个“分享页”，别人能在上面看和下载已经收上来的文件。一般建议勾上。
  • 上传者登记：勾上，对方传之前得先填自己的名字，文件会按名字自动分文件夹存，谁传的一目了然。收作业这种场景强烈建议勾。
  • 单文件上限 / 上传数量上限：限制单个文件多大、每人最多传几个。默认值一般够用。

填完点保存，这个链接就算建好了。

四、链接建好了，怎么发给别人

「收集链接」列表里能看到所有建好的链接。每个链接都有“复制”按钮，会复制两个地址，分别对应两种页面：

  • 收集页链接：给别人传文件用的，发群里。
  • 分享页链接：给别人看/下载文件用的，需要的时候发。

列表里每个链接都能单独编辑（改密码、改限额）、启用/停用（停用后链接就失效，别人打不开）、删除。勾选左边多个链接，再点「批量删除」可以一次删好几个。放心删，已经上传的文件还留在硬盘上，不会没。

五、对方怎么传文件给你

下面站在“上传的人”的角度看一遍，老师你直接把这部分截图发群里都行，省得解释。

第 1 步：打开链接，先填自己的名字

开了“上传者登记”的话，打开页面会先弹个小窗让你填昵称，填完点确认。

第 2 步：把文件拖进来，或者点选

有两种方式：直接把文件拖到中间那块上传区；或者点上传区的按钮自己选文件，一次能选多个。选完点“开始上传”，盯着进度条就行。

文件比较大也无所谓，它支持断点续传，传一半断网了，重新连上会自动接着传，不用从头再来。

第 3 步：看到文件出现在“已上传”里，就成了

手机也能传。用手机浏览器打开链接，操作和电脑上一样。

六、收来的文件，大家怎么查看和下载

因为建链接的时候勾了“开启分享页”，所以你在「收集链接」列表里还能复制到一个分享页链接。把它发给想看文件的人，对方打开就是这个样子：

分享页上每个文件后面有两个按钮：

  • 预览：不用下载，直接在网页里看。图片、PDF、Word/Excel、视频、声音、TXT 文本都支持。
  • 下载：存到自己设备上。

文件多的话，可以勾选好几个一起打包下载（一个 ZIP），或者直接点“下载全部”一把梭。

七、管理面板：左边这几栏都是干嘛的

从飞牛桌面打开应用后，左侧是一排导航，一个个说清楚：

信息面板

一进来看到的就是它。上面是几个数：建了多少链接、有几个活跃、一共收了多少文件、今天收了多少；下面是最近上传的文件，心里先有个数。

收集链接

管理所有收集链接：创建、编辑、复制收集页/分享页地址、启用停用、删除、批量删除。

文件记录

所有收上来的文件都在这里，像一个总仓库。可以按链接筛选、分页翻看；每个文件能预览、下载、删除，勾选多个还能批量打包下载（一个 ZIP）或批量删除。

用户管理（仅管理员）

管理能登录的账号：加人、启停、重置密码、编辑资料，以及生成和管理邀请码。开放注册时，别人凭邀请码就能注册账号。

收集设置

系统配置都在这里。管理员能看到全部设置卡片；普通用户进来只会看到「账号设置」和「我的默认设置」两块。下一节逐项讲。

访问配置（仅管理员）

显示应用的内网访问地址（做反向代理时的上游目标），并可以把自行做好的反向代理公网地址填在这里。应用不再内置反向代理。最后一节详细讲。

实时日志（仅管理员）

记录谁在什么时候登录、建了/删了哪个链接、传了什么、下载了什么、改了哪些设置，可按分类和关键字筛选。

查看文件 / 应用信息（仅管理员）

  • 查看文件：显示上传目录位置，一键调用飞牛文件管理器打开它，直接翻硬盘上的文件。
  • 应用信息：开发者、数据库、版本号、监听端口、数据与上传目录等只读信息，报错时把这里告诉开发者。
收集页和分享页的链接才是发给别人的；管理面板是你自己的后台，别把入口到处发。

八、「收集设置」逐项说清楚

左侧点「收集设置」进来，所有系统配置都在这。管理员从上到下能看到这么多卡片；普通用户只会看到「账号设置」和「我的默认设置」两张。

1. 账号设置

改你自己的账号：

  • 用户名：登录用的账号名。
  • 昵称：这个昵称会显示在收集页和分享页上，别人看到的“xx 邀请您上传文件”用的就是它。不填就显示用户名。
  • 邮箱：用于找回密码与系统通知，留空表示不设置。
  • 原密码 / 新密码 / 确认新密码：改账号信息或密码时需验一次原密码；想换密码就填后面两个，不换留空。（若账号尚未设密码，则不显示原密码。）

2. 页面与品牌

各个页面上显示的字，都在这改。不想折腾可以全不填：

  • 站点标题：显示在浏览器标签和页面顶部。
  • 分享页标题：不填就沿用站点标题。
  • 公网网址：自行做好反向代理后，把公网地址填在这里（与「访问配置」页是同一个值）；不填则链接使用内网地址。
  • 收集页页尾、分享页页尾：页面底部的说明文字，比如“有问题请联系李老师”。
  • 登录页提示：独立后台登录页底部的提示信息。

3. 默认设置（全局）

新建收集链接时的默认值。创建链接时不单独设，就用这里的默认（普通用户这里是「我的默认设置」，仅对自己生效）：

  • 默认最大文件数 / 单文件上限：每个链接默认能收几个文件、单个文件多大。
  • 单次上传个数：上传的人一次最多选几个文件。填 0 表示不限制，最大 500。
  • 通行证有效期：输一次密码（通行证）管多久，到期重新输。
  • 默认链接有效期：新建链接默认的有效期（天）。
  • 收集附件上限：创建链接时上传附件图的最大限制。
  • 收集链接每页 / 上传记录每页：两个列表每页显示几条。
  • 禁止上传的文件类型：黑名单，默认禁 .exe .php .sh .bat 这类危险文件，空格分隔，留空用系统默认。

4. 上传路径

文件默认存在应用数据目录，想存到别的硬盘就填自定义目录（如 /vol2/1000/文件收集）。改完需要在飞牛应用中心给这个目录授权读写，再重启应用才会生效；已有记录的路径会自动迁移。

5. 功能开关

  • 允许用户注册：开启后别人能用邀请码注册你的账号。
  • 启用首页落地页：开启后访问首页看到的是介绍页。
  • 启用根目录模式：开启后，收上来的文件直接按“收集名称”建文件夹放在上传根目录，不再按上传者分层。

6. 邮件（SMTP）

给“忘记密码”等系统通知用的，想让它从你的邮箱发信就配这里：

  • SMTP 服务器：邮箱服务商给的，QQ 邮箱填 smtp.qq.com。
  • 加密方式 / 端口：STARTTLS（587）或 SSL（465），跟着服务商要求选。
  • 邮箱账号、密码/授权码：QQ 邮箱这类一般要用“授权码”，不是登录密码。
  • 发件人名称、发件人邮箱：别人收到邮件时看到的名字和地址。
  • 配完可以点「发送测试邮件」，收到就说明配通了。

7. 数据库备份与恢复

  • 下载数据库备份：把整个数据库导出成 .db 文件存本地，搬家或存档用。
  • 导入数据库备份：上传 .db 覆盖恢复；导入前系统会自动再备份一份当前的，不怕误操作。仅支持由本系统导出的 .db。

九、批量处理文件

文件一多，一个个点太累，新面板里能批量处理：

  • 收集链接列表：勾选左边多个链接，点「批量删除」一次删掉。
  • 文件记录列表：勾选多个文件，能批量打包下载（合成一个 ZIP）或批量删除。收上来几百个文件想一起拷走，用这个最省事。
如果你要一次建很多个链接（比如给 30 个班各建一个作业收集），可以到独立后台 http://你NAS的IP:5557/admin 的「收集链接 → 批量创建」，下载 Excel 模板、填好后上传 CSV 一键生成。这是独立后台保留的功能。

十、想让外面的人也能访问：访问配置

默认情况下，应用只在内网能访问，外面网络进不来。应用本身不再内置反向代理，需要你用现成的工具自行做一层反向代理，再把公网地址回填到「访问配置」页。这样分享出去的收集链接、分享链接就会使用公网地址。这个页面只对管理员开放。

从旧版本升级上来要注意：2.5.0 起内置反向代理整块下线，应用不再监听 HTTPS 端口、也不再读取飞牛系统的证书。之前靠内置反代访问的域名会失效，需要你自己在 Nginx / Lucky / 路由器等处重新配一遍，然后把公网地址回填到本页。
  • 页面只展示应用的访问地址，它就是你反代的「上游/目标」
  • 域名解析、HTTPS 证书、端口转发都在你自己的反代工具里配
  • 回填公网地址后，链接里显示的地址自动换成公网地址

第 1 步：复制应用的访问地址

左侧点「访问配置」，最上面「应用访问地址」卡片显示的是 http://NAS的IP:应用端口/，比如 http://192.168.1.10:5557/，点右侧按钮一键复制。反代里的「目标地址/上游地址」就填它。

第 2 步：自行做反向代理

用你顺手的任意方式把服务暴露出去都可以，例如 NAS 上已装的 Nginx、路由器/OpenWrt 的反代插件、Lucky、云服务器上的 Nginx，或者 frp 之类的内网穿透工具。三个要点：

  1. 上游填内网地址：第 1 步复制的地址，IP 和端口别写错；
  2. 域名和证书在反代侧配：要走 HTTPS 就在反代工具里配好证书，本应用不参与证书管理；
  3. 原样转发请求：不要剥掉 Host 头，也不要改写路径前缀。

Nginx 写法参考

把 file.example.com 换成你的域名，192.168.1.10:5557 换成「应用访问地址」卡片上的实际 IP 和端口：

server {
    listen 443 ssl;
    server_name file.example.com;

    ssl_certificate     /path/to/fullchain.pem;
    ssl_certificate_key /path/to/privkey.pem;

    location / {
        proxy_pass http://192.168.1.10:5557;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        client_max_body_size 64g;   # 大文件上传，别让 Nginx 先拦下来
    }
}

用 Lucky、群晖反代或云服务器反代时思路一样：目标填内网地址、保留 Host 头、把上传体积上限调大（本应用单文件最大 64 GB）。

不要把应用挂在子路径下（例如 https://example.com/files/）。应用按根路径设计，子路径会导致页面、接口和上传都打不开，请用独立域名或独立端口。
如果 NAS 没有公网 IP（运营商的“大内网”），只配反代也连不进来，还需要做内网穿透，或者在路由器上开端口转发并向运营商申请公网 IP。

第 3 步：把公网地址填回来

反代配通、在外网用手机流量能打开之后，回到「访问配置」页，在下方「公网访问」卡片里填入完整的公网地址——要写全、包含端口，例如 https://file.example.com:8443（反代用 443 或 80 标准端口时端口可省略），点保存。地址必须以 http:// 或 https:// 开头。

保存后，收集链接和分享链接里的域名就会换成这个公网地址，发给别人的就是外网可打开链接。「收集设置 → 页面与品牌 → 公网网址」填的是同一个值，改哪边都一样。

这里填的只是「链接里显示的域名」，不会帮你做端口转发。外网能不能访问，取决于你的反向代理和网络环境，与这里填不填无关。
只在内网（家里、办公室）用，就完全不用管这一章：不填公网地址时，链接自动使用内网地址。
